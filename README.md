# Beryllium

**Status: defunct — acquired by Dream Sports (Dream11), October 2023. No API surface.**

Beryllium was a Singapore- and Delhi-based sports and trading game development platform founded in 2018/2019 by Amay Makhija. Its consumer product, **Sixer**, was a fantasy cricket game in which users bought "Up" or "Down" virtual stocks in professional cricketers, with prices moving on in-game batting, bowling, and fielding metrics.

The company raised roughly $3.6M across two rounds, including a $3M pre-Series A in June 2021 led by **Bullpen Capital**, with participation from Genting Ventures (Singapore) and Velo Partners (UK).
